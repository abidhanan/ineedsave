Pinterestの動画・画像をスマホに保存する方法

2026年10月13日

Pinterestでレシピ動画やインテリアのアイデア、短いチュートリアルを見つけて、ネットにつながっていなくてももう一度見たいと思ったことはありませんか？ Pinterestの保存機能はピンをアプリ内のボードに追加するだけなので、ファイルが実際にスマホのギャラリーに入るわけではありません。この記事では、Pinterestの動画や画像をギャラリーに保存する方法を紹介します。簡単で無料、追加のアプリもログインも不要です。

使うツールはI Need Save。スマホでもパソコンでもブラウザから直接開けるWebベースのダウンローダーです。Pinterestのほか、TikTok、Instagram、Facebook、X (Twitter) など、いくつかのサービスの公開投稿にも使えます。

準備するもの

  • 保存したいピンのリンク。そのピンが公開されていることを確認してください。
  • ブラウザ（Android の Chrome や iPhone の Safari など何でもOK）。
  • ある程度安定したインターネット接続（特に長い動画の場合）。

I Need Save でアカウントを作る必要も、アプリをインストールする必要もありません。

スマホでPinterestの動画をダウンロードする方法

手順は Android も iPhone も同じです。

  1. Pinterestアプリを開き、保存したい動画ピンを探します。
  2. シェアボタンをタップし、リンクをコピーを選びます。
  3. ブラウザを開いてI Need Save のダウンロードページにアクセスします。
  4. 入力欄にリンクを貼り付けるか、貼り付けボタンをタップするだけでもOKです。
  5. ダウンロードを押して、ファイルの選択肢が表示されるまで少し待ちます。
  6. 好きな画質の動画など、欲しいオプションを選びます。

ボタンが準備中…に変わったら、まだページを閉じないでください。映像と音声を結合したり、ストリームを MP4 に変換したりと、動画を処理している最中です。終わればダウンロードが自動で始まります。

Pinterestの画像を保存する方法

画像のピンも、やり方はほとんど同じです。ピンのリンクをコピーして I Need Save に貼り付け、ダウンロードを押します。オプション一覧から写真またはサムネイルを選びましょう。動画ピンのカバー画像だけが欲しいとき、たとえば個人的なデザインの参考にしたいときにも便利です。

動画の画質を選ぶコツ

ダウンロードを押すと、たいてい 360p、720p、1080p などの画質の選択肢が表示されます。表示される内容は元の動画によって変わるので、すべてのピンに 1080p があるわけではありません。

  • 360p：データ通信量が限られているときや、スマホの容量が残り少ないときに。
  • 720p：鮮明さとファイルサイズのバランスがよい選択肢。
  • 1080p：最も鮮明で、大きな画面で見るのに向いています。

詳しくは360p・720p・1080p の画質の違いの記事をご覧ください。

動画のほかに音声のオプションもあります。オリジナル画質の音声か、動画から変換した MP3 192 kbps を選べます。ピンのBGMだけが欲しいときに便利です。

Pinterestのファイルはどこに保存される？

保存先は使っている端末によって異なります。

  • Android とパソコン：ファイルは「ダウンロード」フォルダに入ります。ギャラリーアプリに表示されるまで、少し時間がかかることがあります。
  • iPhone と iPad（Safari）：ファイルは「ファイル」App →「ダウンロード」に入ります。動画を「写真」App に入れるには、「ファイル」App で動画を開き、共有ボタンをタップしてビデオを保存を選びます。

それでもファイルが見つからない場合は、AndroidとiPhoneでのダウンロードファイルの保存先のガイドを参考にしてください。

ファイルはPinterestからあなたのデバイスへ直接送られ、I Need Save のサーバーには保存されません。大事なファイルは、あとで見つけやすい場所に保存しておきましょう。

Pinterestのダウンロードに失敗するときは

次のような原因で失敗することがあります。

  • ピンが非公開アカウントのもの、またはログインしないと見られない。
  • コンテンツが特定の地域に制限されている。
  • 貼り付けたリンクが不完全、またはコピーを間違えている。

シェアボタンから直接リンクをコピーし直して、もう一度試してみてください。なお、非公開のコンテンツ、ログインが必要なコンテンツ、地域制限のあるコンテンツはダウンロードできません。

賢く使おう

ピンの多くは、写真やイラスト、クリエイターが作った動画など、ほかの人の作品です。参考資料として保存したり、オフラインで見たりといった個人的な用途だけにダウンロードしましょう。再投稿したい場合は、事前に作者の許可をもらい、クレジットを記載してください。

よくある質問

I Need Save でのPinterest動画のダウンロードは無料ですか？

はい、無料です。ブラウザでサイトを開くだけで、アプリもログインも必要ありません。

パソコンでも使えますか？

使えます。パソコンのブラウザでピンを開いてリンクをコピーし、I Need Save に貼り付けてください。ファイルは「ダウンロード」フォルダに保存されます。

動画がすぐにギャラリーに表示されないのはなぜですか？

Android では、ギャラリーがファイル一覧を更新するのに少し時間がかかることがあります。iPhone では、共有メニューを使って「ファイル」App から「写真」App に動画を保存する必要があります。
