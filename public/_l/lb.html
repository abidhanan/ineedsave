Heefeg Froen

Ass I Need Save gratis?

Jo, komplett gratis. Keng Umeldung, kee Login a keng App néideg.

Wou gi meng Fichieren ofgespäichert?

Op Android an op Computeren landen d'Fichieren am Dossier Downloads. Op iPhone an iPad (Safari) gi se an der App Dateien → Downloads gespäichert. Vun do aus kanns de se mam Knäppchen „Teilen“ an d'Fotoe späicheren.

Firwat kënne verschidde Videoen net erofgeluede ginn?

Eise Server kann net op privaten Inhalt, op Inhalt mat Login-Pflicht oder op regional gespaarten Inhalt zougräifen. Kuck, datt de Post ëffentlech ass, a probéier et dann nach eng Kéier.

Wéi lueden ech MP3 erof?

Nodeems de Link veraarbecht gouf, wiel ënner Audio d'Optioun MP3. Den Toun gëtt aus dem Video geholl an an MP3 mat 192 kbps ëmgewandelt.

Hunn TikTok-Videoen e Waasserzeechen?

Mir huelen ëmmer léiwer d'Versioun ouni Waasserzeechen, wann se disponibel ass. Optioune mat Waasserzeechen si mat Waasserzeechen markéiert.

Gi meng Fichieren op ärem Server gespäichert?

Nee. D'Fichiere ginn direkt vun der Original-Plattform op däin Apparat geschéckt a ginn net op eisem Server gespäichert.
