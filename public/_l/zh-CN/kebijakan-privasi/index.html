隐私政策

自2026年10月21日起生效

I Need Save（ineedsave.com）是一款用于下载社交媒体上的视频、图片和音频的免费工具，由 Abid Hanan Wicaksono 运营。本政策说明您使用本网站时我们会处理哪些数据，以及我们如何处理这些数据。我们有意尽可能少地收集数据：您无需注册、登录，也无需提供姓名或电子邮件地址即可使用本服务。

我们处理的数据

  • 您粘贴的链接。链接发送到我们的服务器，仅用于查找可下载的媒体。我们不会将链接存储在数据库中，也不会将其与您的身份相关联。
  • 媒体文件。在可能的情况下，您的浏览器会直接从原平台（例如 Instagram、Facebook 或 X）的服务器下载文件。当文件需要处理（例如合并视频和音频或转换为 MP3），或者平台不允许直接下载时，文件会以流式传输的方式经由我们的服务器发送到您的设备，而不会被存储。
  • 技术数据。与几乎所有网站一样，我们的托管服务提供商（Vercel）出于安全和运营目的，会记录请求的技术数据，例如 IP 地址、浏览器类型和访问时间。这些日志仅根据 Vercel 的政策临时保存。
  • 文章统计。浏览量、点赞数和分享数按每篇文章的总数存储，不包含任何可识别您身份的数据。

Cookie 和浏览器存储

  • ins-lang：记住您选择的语言，有效期一年。
  • dl_…：仅持续几秒钟的临时 Cookie，用于标记下载已开始。
  • 本地存储（localStorage 和 sessionStorage）：记住您点赞过的文章，并防止同一次访问被重复计算。这些数据保留在您的设备上。
  • 来自 Google Analytics 和 Microsoft Clarity 的第三方分析 Cookie，详见下文。

分析

我们使用分析工具来了解网站的使用情况并加以改进：

  • Vercel Web Analytics：不使用 Cookie 的匿名访问统计。
  • Google Analytics 4（Google LLC）：使用 Cookie 衡量您打开的页面、您所在的大致国家/地区、您的设备类型，以及点击下载按钮等事件。数据由 Google 依据Google 隐私权政策进行处理。
  • Microsoft Clarity：在您开始与页面互动后加载。Clarity 会记录点击和滚动等互动，用于生成热图和会话录制，并会遮盖您在输入框中键入的内容。数据由 Microsoft 依据Microsoft 隐私声明进行处理。

您可以通过在浏览器设置中阻止第三方 Cookie、使用跟踪器拦截工具或安装 Google Analytics Opt-out Browser Add-on 来选择退出分析。网站仍可完全正常使用。

第三方服务

  • Vercel Inc. 提供托管服务。其服务器可能位于您所在的国家/地区之外。
  • Google Fonts 用于显示某些文字（例如阿拉伯文、泰文或日文）。加载字体时，Google 可以看到您的 IP 地址。
  • 媒体的原平台。当文件被直接下载时，该平台可以看到您的 IP 地址，就像您自己打开该内容时一样。
  • 分享按钮（WhatsApp、Facebook、X、LinkedIn、Telegram）仅在您点击时才会联系这些服务。

安全与共享

与本网站的所有连接均使用 HTTPS。我们不会出售、出租或交易个人数据。我们仅在运营网站所需的范围内与上述服务提供商共享数据，或在法律要求时共享数据。

儿童

本服务不面向 13 岁以下的儿童，我们不会在知情的情况下收集儿童的个人数据。

您的权利

根据您所在的地区，例如依据印度尼西亚《个人数据保护法》（2022年第27号法律）或欧盟《通用数据保护条例》（GDPR），您可能有权访问、更正或删除您的个人数据，并撤回对数据处理的同意。由于我们几乎不存储任何可识别您身份的数据，大多数请求只需清除浏览器中的 Cookie 即可解决。对于由 Google 或 Microsoft 处理的数据，您也可以使用其服务的隐私设置。如有其他事宜，请与我们联系。

本政策的变更

本政策可能会不时更新。变更自在本页面发布时生效，生效日期显示在页面顶部。
